## 四、理论基础是否够用（2026-08-31 结论）

**V1 足够。** 依据：

1. **判分不依赖书籍**——向听数/进张是数学计算，正确性靠 golden 用例 + 第三方对拍保证（engine.md）
2. **讲解出处的落点**：PRD 5.2 七级分类表里，L1-L7 每级「核心理论依据」引用的章节
   （79博客·麻雀的基础 4/8-10、牌效率 2-7/13-20、第七章防守、第九章攻守判断；
   Riichi Book I Ch3.3/Ch4/Ch7-8）**全部落在已入库的两份资料内**
3. ウザ克仅贡献分类骨架，其骨架对应的实质内容有中文（79博客）+ 英文（RBI）双来源交叉
4. 缺口仅剩「ウザ克式复合形细类目命名」——出题到 L3 时按需在线核对（见第二节），不阻塞任何里程碑

**升级路径（明确触发条件）**：出题阶段若确认已入库资料对某类目覆盖不足 → 购买对应实体书
（日亚/代购）作案头参考；仍不引入电子扫描版入库。
