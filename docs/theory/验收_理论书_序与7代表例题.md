## 一、序：这本书写给谁、怎么读

这是一本讲「**牌效率**」的小册子——不管你是打国标、四川麻将还是日麻，
只要和牌都是「4 面子 + 1 雀头」，下面这套读牌方法就通用。

我们不教规则（你大概已经会了），也不教怎么读别人脸色、怎么算番数（那超出本书）。
只讲一件事：**手里这 14 张，打哪一张最接近和牌，为什么。**

书里把这件事拆成七个台阶，一章一步：

| 章 | 讲什么 | 一句话 |
|---|---|---|
| 1 | 目标：和的形状 | 先认得「面子、雀头、搭子、浮牌」长什么样 |
| 2 | 尺子：向听数与进张 | 用「差几步 + 剩几张」给每手牌量出进度 |
| 3 | 复合牌：一张顶几用 | 三张四张叠一起，读法比看单张多 |
| 4 | 五搭子：把整手当 5 块看 | 别数 14 张，数「几块拼图」 |
| 5 | 一向听与听牌：临门一脚 | 差一张就和的形状，和哪几张、张数多少 |
| 6 | 不倒退：诱惑与纪律 | 已经到手的进度，别为了「看起来多」让出去 |
| 7 | 只管速度：本书的边界 | 速度算到头了，剩下的是打点与攻守（不讲） |

**怎么读**：从头读到尾即可，每章配一道代表例题当场检验。例题一律同一套格式：
先读牌（把牌分成块）→ 给正解 → 讲为什么 → 把新手常犯的错逐个拆穿。

> 全书没有「 App 」「关卡」「训练」等字样；题牌全是原创组合，不抄任何出版物原文。
> 图与数字均有工具核验（`hand-svg.ts` 出图、引擎 probe 核数），标注在每题末。

## 二、开篇思维导图（缩进大纲，正文首章会画成图）

```
和牌  ←  4 面子 + 1 雀头
│
├─ 面子：顺子 123 / 刻子 111        （成三张才算一块）
│     └─ 面子之前是「搭子」：两面 23 / 嵌张 35 / 边张 12 / 对子 11
├─ 雀头：一对同牌（11）              —— 常常藏在大牌块里，先找它
└─ 浮牌：面子、搭子、雀头全够之后多余的单张 → 最早被打
│
和牌速度  ←  向听数（还差几步）× 进张（剩几张能推进）
│     └─ 步数优先于张数：能听牌，就不回身去等更多张
│
整手组织  ←  五搭子原理：数「块」不数张
│     ├─ 面子/搭子/雀头都算一块，理想是 5 块（4 面子候补 + 雀头）
│     ├─ 超过 5 块（搭子过剩）→ 拆最差的一块
│     └─ 复合牌（帽子 1123 / 四连 3456 / 中膨 4556 …）是同一块里藏了更多路
│
临门一脚  ←  一向听 → 听牌
│     └─ 听牌要挑「进张张数多」的听（两面 8 张 > 对碰 4 张 > 单骑 3 张）
│
纪律  ←  不倒退：已到手的听牌/进度，别为了「改良空间更大」拆掉
│
边界  ←  本书只管速度；打点、防守、攻守取舍 → 另书不展开
```

## 三、七章代表例题（每章一道，试难度曲线与讲解风格）

难度：★ 入门 → ★★★ 需要想。数字行 = `npx tsx content/build/probe.ts "…"` 实跑结果。

### 例 1-1｜第1章：11万 是雀头，不是面子 ★ 入门

**牌面**（万→筒→条）

![1123万 123筒456筒 789条 9筒](assets/书例1_认雀头.svg)

**先读牌**：三副面子已经摆好了：123筒、456筒、789条。剩下 1123万 + 一张 9筒。
1123万 里藏着 11万 一对——**先认出雀头**，剩下的 23万 就自动成两面搭子，等 1万/4万。

**正解**：打 **9筒**。

**为什么**：9筒 谁也不挨，是纯浮牌。打掉它，手牌就是
「11万雀头 + 23万两面搭 + 三面子」= **已听牌**，和 1万/4万，共 6 张（1万手里已有 2 张剩 2，4万 全剩 4）。

**新手常犯的错，逐个说清为什么不行**：

| 打了 | 会怎样 | 哪里不对 |
|---|---|---|
| **1万** | 单骑 9筒，只剩 3 张 | 把 1123万 硬拆成 123万面子 + 1万 浮——雀头没了，只能单吊 9筒 |
| **2万 / 3万** | 退回 1向听（28/24 张） | 拆掉 23万 两面搭，手牌重新变回「差一步」 |
| **1筒 / 4筒** | 退回 1向听 | 拆已经成型的完整面子，是最大忌讳 |

> 一句话记住：**读牌先找雀头；它藏在复合块里时，别把它拆进面子。**
> 核验行：切9p → 0向听 / 6张 [1m 4m]

### 例 2-1｜第2章：尺子怎么用——都差一步，比谁剩的进张多 ★ 入门

**牌面**

![123456万 9万 789筒 12条 45条](assets/书例2_向听数.svg)

**先读牌**：123万、456万、789筒 三面子；12条、45条 是两个搭子。数一下——
还差一副面子 + 一个雀头才成型，也就是 **1向听**（差一步听牌）。9万 是浮牌。

**正解**：打 **9万**。

**为什么**：尺子的用法是「步数相同，比张数」。打 9万 保留两个搭子，
1~6条 六种牌、共 **20 张** 都能推进这手牌；打任何一张条子搭子牌，进张都会缩水。

**新手常犯的错，逐个说清为什么不行**：

| 打了 | 会怎样 | 哪里不对 |
|---|---|---|
| **5条** | 进张掉到 13 张 | 拆了 45条 两面，浮牌 9万 还死攥在手里 |
| **2条** | 进张只剩 14 张 | 12条 边张搭子被拆，少了一半路线 |
| **1万 / 4万** | 退回 2向听（46 张） | 动完整面子，直接倒退一大步 |

> 一句话记住：**浮牌先走；要拆就拆最差的，别动最值钱的两面。**
> 核验行：切9m → 1向听 / 20张 [1s..6s]

### 例 3-1｜第3章：帽子形 1123，多的一张就是它 ★★ 进阶

**牌面**

![1123万 456筒 99筒 789条 55条](assets/书例3_帽子形.svg)

**先读牌**：456筒、789条 两面子；99筒、55条 两对；1123万 是「**帽子形**」——
4 张里其实只多 1 张：它已经包含 123万 这整副面子，多的那张是 1万。

**正解**：打 **1万**。

**为什么**：打掉帽子多余的那张 1万，1123万 立刻兑现成 123万 面子。
于是整手 = 三面子（123万/456筒/789条）+ 两对子（99筒、55条）= **对碰听牌**，
和 9筒/5条，共 4 张。

**新手常犯的错，逐个说清为什么不行**：

| 打了 | 会怎样 | 哪里不对 |
|---|---|---|
| **9筒 / 5条** | 退回 1向听（25/32 张） | 拆了对子去追「进张多」，但手牌从能听牌退回了差一步 |
| **9条** | 1向听，12 张 | 789条 是完整面子，拆它最亏 |
| **4筒 / 2万** | 1向听（12/10 张） | 动到面子或帽子本体，都没让 1123 兑现 |

> 一句话记住：**帽子形 1123/1223/2334，先想哪张是「多出来的」，打它就是兑现面子。**
> 核验行：切1m → 0向听 / 4张 [9p 5s]

### 例 4-1｜第4章：四对子，先从重叠处下手 ★★ 较难

**牌面**

![22万 567万 3345筒 99筒 88条 9条](assets/书例4_四对子.svg)

**先读牌**：567万 一副面子。剩下 22万、33筒、99筒、88条 四个对子，
外加 45筒 两面、9条 一张浮牌——对子太多，五搭子挤爆了，必须拆一个。

**正解**：打 **3筒**。

**为什么**：3345筒 是「33 对 + 45 两面」叠成的**重叠形**——先在这里拆，
捐一张 3筒 直接换回完整面子 345筒；22万、99筒、88条 三对**一个不丢**，
还能摸 2万 / 9筒 / 7条 / 8条 再成刻子，共 **10 张** 进张（1向听）。

**新手常犯的错，逐个说清为什么不行**：

| 打了 | 会怎样 | 哪里不对 |
|---|---|---|
| **2万** | 退回 2向听 | 22万 是纯对子，拆了没重叠可救，一对直接报废 |
| **9筒** | 退回 2向听 | 99筒 同样纯对子，拆了就没了 |
| **8条** | 1向听，8 张 | 剩 89条 等 7条（4 枚），不算致命，但 10 张 > 8 张 |
| **9条** | 1向听，6 张 | 889条 拆成纯对子 88，进张只剩 2 枚 8条，最亏的拆法 |

> 一句话记住：**对子过剩时，先拆有重叠的（对+两面），纯对子能不动就不动。**
> 核验行：切3p → 1向听 / 10张 [2m 9p 7s 8s]

### 例 5-1｜第5章：五连自动三面，别去动它 ★★ 进阶

**牌面**

![123万 456筒 34567条 99条 9万](assets/书例5_五连三面.svg)

**先读牌**：123万、456筒 两面子；99条 雀头。剩 34567条 一个**五连** + 9万 浮牌。
五连是全书最宝贝的复合形：**5 张里同时藏着「面子 + 搭子」两种用法**。

**正解**：打 **9万**。

**为什么**：9万 谁也不接（万子已排到 123）。打掉它，五连条子自己变出听牌——
34567 可拆成「345面子 + 67搭」或「567面子 + 34搭」……两种拆法并起来，
听 **2条/5条/8条** 三面，共 **11 张**（2条、8条 各 4，5条 手里 1 张剩 3）。

**新手常犯的错，逐个说清为什么不行**：

| 打了 | 会怎样 | 哪里不对 |
|---|---|---|
| **7条 / 3条** | 退回 1向听（41/37 张） | 看着进张一大片，其实把五连拆了——步数倒退 |
| **9条** | 1向听，23 张 | 99条 是雀头，拆了雀头没了 |
| **1万 / 4筒** | 1向听（19/19 张） | 动完整面子换浮牌 9万 留着，方向反了 |

> 一句话记住：**五连（34567 等）自动送三面听，要做的只有一件事：别切它。**
> 核验行：切9m → 0向听 / 11张 [2s 5s 8s]

### 例 6-1｜第6章：不退 vs 退——多 20 张的诱惑 ★★★ 压轴

**牌面**

![123万 456筒 99筒 223条 789条](assets/书例6_不倒退.svg)

**先读牌**：123万、456筒、789条 三面子；99筒 雀头。条子剩 223条——
它可以读成「23条 两面搭 + 多一张 2条」。也就是说：**只要把多出的 2条 让掉，就听牌了。**

**正解**：打 **2条**（让掉 223 里多出的那张）。

**为什么**：切 2条 → 剩 23条 两面搭 → 听 1条/4条，**8 张，已听牌（0向听）**。
真正难的是管住手：切 9筒（退回 1向听）能换来 28 张「进张」，看着多三倍不止——
但那是**倒退**，你得再摸一手才回到现在的位置。尺子的铁律：**步数优先于张数，能听就不退。**

**新手常犯的错，逐个说清为什么不行**：

| 打了 | 会怎样 | 哪里不对 |
|---|---|---|
| **9筒** | 退回 1向听，28 张 | 拆了雀头去追「进张多」——已到手的听牌让出去了，白白退一步 |
| **3条** | 也听牌，但只 4 张 | 22条 对碰等 2条/9筒（4 张），比留 23条 两面（8 张）少一半 |
| **1万 / 4筒** | 退回 1向听（20 张） | 动完整面子，同样是无谓倒退 |

> 一句话记住：**已经能听牌就听；别为了「看起来多 20 张」把进度退回去。**
> 核验行：切2s → 0向听 / 8张 [1s 4s]；切9p → 1向听 / 28张

### 例 7-1｜第7章：都 0 向听、都 4 张——并列，判分都给对 ★★ 进阶

**牌面**

![112万 456万 456筒 99筒 789条](assets/书例7_并列最优.svg)

**先读牌**：456万、456筒、789条 三面子；99筒 雀头。万子剩 112万——
可读成「11万 雀头候补 + 2万」或「1万 对子 + 12万」……正因如此，这手有两条都走得通的路。

**正解**：打 **1万 或 2万 都对**（并列）。

**为什么**：切 2万 → 留 11万 + 99筒 对碰，听 1万/9筒（4 张）；
切 1万 → 剩 12万 边张等 3万，也是 4 张。**向听数相同、进张张数相同**，引擎判两条
都是最优，判分两个都算对。到了这种时候，速度尺子已经到头，选哪个要看打点/防守——
那超出本书范围，正是第 7 章要说的边界。

**新手常犯的错，逐个说清为什么不行**：

| 打了 | 会怎样 | 哪里不对 |
|---|---|---|
| **9筒** | 退回 1向听，27 张 | 拆雀头追张数，老毛病（见第 6 章） |
| **4万 / 6万** | 退回 1向听（16 张） | 456万 是完整面子，拆了没意义 |
| **5万** | 退回 1向听（12 张） | 三面子少一副，进度倒退 |

> 一句话记住：**两条路真分不出高下时，承认并列，判分都给对——别硬编一个理由。**
> 核验行：切1m / 切2m → 均 0向听 / 4张

## 四、这套样张要你验收的点

1. **难度曲线是否顺**：★→★★（例 3、4、5）→★★★（例 6）→★★（例 7 边界收尾），
   是否符合「第一章给新手、最后一章是压轴」的预期？
2. **四段式风格**（题头 → 牌面图 → 先读牌/正解/为什么 → 错选解剖表）读起来顺不顺？
   是否每道都够「像一本书」，而不是像 App 习题解析？
3. **七章粒度**：每章 1 个代表够不够？如果够，后续每章扩到 3~5 例、全书约 30 例，
   按这个模板批量写。
4. **牌面图观感**：7 张 SVG 是否清楚？`--mark` 高亮正解是否符合预期？
5. **记法**：正文全用「万/筒/条 + 数字」，无 `m/p/s` 泄漏、无 App 字样、无字牌，是否达标？
