## 一句话

## 七级训练分类(内容骨架)

| 级 | 名称 | 训练内容 |
|---|---|---|
| L1 | 基本形与搭子识别 | 面子 / 搭子(两面 / 嵌张 / 边张 / 对子)/ 雀头辨认 |
| L2 | 搭子价值与进张计算 | 进张张数、搭子排序、浮牌取舍 |
| L3 | 复合形与多面张 | 两嵌 / 中膨 / 亚两面 / 四连五连的读法与切法 |
| L4 | 五搭子原理与拆搭 | 块数法、超载拆搭、对子过剩 |
| L5 | 一向听与听牌选择 | 好形愚形判别、听牌留法二选一 |
| L6 | 改良与向听倒退 | 不倒退原则、并列抉择 |
| L7 | 综合判断 | 整序、多角度同指、攻守(注脚级) |

- 搭子价值排序:两面 > 两嵌 > 嵌张 > 边张;对子特殊(雀头或刻子候补),不纳入排序
- 理论出处勾稽(每级引用的 79博客 / Riichi Book I 章节)见
  [SOURCES.md](references/SOURCES.md) §五勾稽表,出题时只标章节定位
- 完整目标 200 题(30/35/30/40/30/20/15);起步下限 L1-L3 ≥8、L4-L7 ≥10
  (2026-09-02 修订);现库 68 题(2026-09-03 分布 8/8/11/10/11/10/10);实时分布用 `npm run bank:dist`
  对照本表打印缺口

## 题型(占比)

`what_to_discard` ≥70% / `ukeire_compare` ~15% / `mentsu_identify` ~10% / `wait_choose` ~5%。
单题 Schema、answer 结构与判分口径见 [content/schema/question.schema.json](../content/schema/question.schema.json)，
机器校验 `npm run bank:verify`。

## 关键行为口径

| 项 | 口径 |
|---|---|
| 判分 | 比对 `answer.correct`(并列全对),不实时算引擎(快照出题时注入) |
| 讲解 | 三段式:最优解 + 进张对比 + 理论出处;答错 / 主动查看均展示 |
| 关卡 | 每关 8-12 题;结算 ≥80% 解锁下一关;题库不足允许复用并提示 |
| 水平测试 | 8 题只抽 `what_to_discard`、覆盖 L4-L7 → 定级 + 推荐起始级,可重测覆盖 |
| 离线 | 断网全部功能可用;联网失败(更新 / 版本检查 / 远程配置)静默降级 |
| 数据 | 全本地(localStorage + IndexedDB),卸载即丢,设置页提示;无上行 |
| 特殊牌型 | 七对 / 国士不进 V1 判定主流程,仅标注 |
| 自测期关卡全开 | `Home.tsx` 的 `ALL_LEVELS_OPEN` 常量旁路解锁(2026-09-02 裁定),上线前翻回 |

## Web 页面与存储(现状以代码为准)

信息架构(UI v2):底部 5 Tab = 首页 / 专项 / 题库 / 评测 / 我的,其余为沉浸页。

| 路由 | 内容 |
|---|---|
| `/` | 今日进度、薄弱强化、能力概览、快捷训练 |
| `/special`、`/special/:cat` | 5 专项卡片 / 专项详情(考点 chips 进 `/drill`) |
| `/bank` | 全题库浏览与筛选 |
| `/eval` | 水平测试入口与定级结果 |
| `/mine`、`/settings` | 记录 / 错题本入口;题库更新、皮肤、清除数据 |
| `/levels`、`/levels/:level` | 七级卡片 / 关卡详情(考点 chips) |
| `/quiz/:level/:stage`、`/result/…` | 做题页(手牌点选即判)/ 结算 |
| `/drill/:kp`、`/drill?cat=` | 专项组卷:精确考点或分类过滤,乱序不补量上限 12,计错题不计关卡进度 |
| `/wrong-book`、`/placement` | 错题本(答对移出)/ 水平测试 |

本地存储(键前缀 `nk.`):`progress` / `wrong_book` / `placement` / `settings` →
localStorage;`bank`(库名 `nanikiru` / store `bank` / key `merged`)+
`update_state` → IndexedDB,读取带 1500ms 超时竞速静默降级内置题库。

牌面:全站单组件 `<Tile>` + 皮肤注册表(`apps/web/src/tiles/`),SVG 实现,
换皮只动 skin 层;正式美术用户自筹,开发期用 placeholder。

自测通道(改对应层后必跑,收口命令 `npm run selfcheck`):
`e2e:smoke`(闭环冒烟)/ `e2e:bank` + `e2e:update`(题库更新链)/
`npm test`(引擎 golden)。
